##  Project Overview

This repository contains my **Digital Literacy Portfolio**, developed as part of my role as a *Student Digital Ambassador*.

The objective of this project is to help students:

* Build a professional digital presence
* Communicate responsibly online
* Use coding and collaboration platforms effectively
* Practice proper email etiquette
* Understand cybercrime risks and prevention strategies

All five modules of the course are represented through practical tasks, reflections, and documented deliverables organized within this repository.
